# 2026-10-23: recherche de la conception de la machine à dessiner

**Séance :** planifiée / hors créneau · **Durée :** 3 h

## Fait

Durant cette séance, nous avons encore recherché les différentes façons de conception d'une machine à dessiner car durant un cours de méthodologie de projet, un prof nous a dit que ce n'était pas obligé que ça soit sur une feuille. Donc on a recherché sur Internet puis nous avons regardé différentes machines comme une machine à dessiner avec du sable, sur un mur ou en pantographe. On a préféré la machine qui dessine sur sur sable (table cinétique). Enfin, nous avons regardé les différents prototypes de cette machine.

## Pourquoi

On aimerait avoir une machine original qui ne dessine pas sur une feuille.
